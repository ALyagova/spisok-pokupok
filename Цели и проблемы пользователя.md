# Цели и проблемы пользователя

Этот файл — постоянный контекст проекта. Он должен оставаться в репозитории после удаления временной спецификации и помогать агентам понимать, зачем существует продукт.

## Для кого продукт

Для семьи, которая ведёт один общий список покупок на телефонах. Домохозяйство — семья из четырёх человек с детьми 3 и 9 лет.

## Проблемы пользователя

- Перед походом в магазин нужно быстро вспомнить и собрать обычные продукты, не набирая всё с нуля.
- В магазине легко забыть, что уже положено в корзину, и приходится мысленно держать список.
- Повторяющиеся покупки меняются от похода к походу: нужен регулярный шаблон, который легко дополнить или сократить.
- Не все нужные пользователю продукты окажутся во встроенной библиотеке; приложение должно учиться на добавленных товарах, а не заставлять вводить их заново.
- При поиске в категории лишние товары из других разделов создают путаницу.
- Перед походом в магазин нескольким членам семьи нужно успеть внести свои пожелания в один список.
- Пользователю нужен лёгкий личный инструмент, а не сервис с регистрацией, настройками аккаунта, рекламой и уведомлениями.

## Цели пользователя

- Дома составить понятный список покупок за несколько нажатий.
- Выбирать товары через привычные категории, а не искать среди всех продуктов сразу.
- Быстро повторить обычный поход, используя готовый шаблон или недавний список.
- Указать дома важные детали: заметку к товару.
- В магазине видеть только нужные позиции, сгруппированные по категориям, и просто отмечать купленное галочкой.
- Сохранять новые личные товары и категории, чтобы приложение становилось удобнее со временем.
- При необходимости повторять один из двух последних походов.

## Задачи продукта

1. Снизить усилие на составление регулярного списка покупок.
2. Дать пользователю контроль над библиотекой товаров, категориями и готовым списком.
3. Сделать использование в магазине быстрым и читаемым на экране телефона.
4. Запоминать поведение пользователя: сохранённые товары и частые выборы внутри категории.
5. Давать семье общий список по секретной ссылке без учётных записей и лишних действий.

## Принципы опыта

- Сначала категории, затем товары внутри выбранной категории.
- Один экран — одна понятная задача.
- Частые товары должны быть ближе и выше редких.
- Поиск всегда ограничен текущей категорией и помогает с неточным вводом.
- Купленный товар должен быть виден, но не мешать просмотру оставшихся позиций.
- Интерфейс спокойный и нейтральный, а визуальные решения должны использовать дизайн-систему владельца проекта.

# Дизайн-система «Список покупок»

## Назначение

Это постоянный источник правил интерфейса приложения. Дизайн должен помогать быстро составлять список дома и отмечать покупки в магазине, а не выглядеть как интернет-магазин.

Вдохновение: светлый минималистичный продуктовый интерфейс, фотографии или иллюстрации товаров рядом с названиями, крупные понятные карточки и минимум визуального шума. Не копировать буквально интерфейсы из референсов.

## Принципы

1. **Товар узнаётся с первого взгляда.** У товара есть название и компактное визуальное изображение.
2. **Одно касание — одно действие.** Добавление товара и отметка покупки должны быть мгновенными.
3. **Сначала содержание.** Белое пространство, ясная иерархия, минимум украшений и служебных элементов.
4. **Мобильный приоритет.** Все интерактивные элементы удобны для нажатия одной рукой на iPhone.
5. **Спокойный, не «магазинный» характер.** Нет цен, рекламных баннеров, бейджей скидок, рейтингов или перегруженных витрин.

## Цвета

Использовать светлую нейтральную основу и один спокойный зелёный акцент. Точные значения — базовые токены; при появлении брендовых значений заменить их централизованно.

| Токен | Значение | Использование |
|---|---:|---|
| `color.background` | `#FFFFFF` | Основной фон экрана |
| `color.surface` | `#F8F8F6` | Мягкий фон секций и полей |
| `color.surface-muted` | `#F1F1ED` | Плашки, состояния нажатия |
| `color.text-primary` | `#20231F` | Основной текст |
| `color.text-secondary` | `#6D736B` | Второстепенный текст, подписи |
| `color.border` | `#E5E7E2` | Границы и разделители |
| `color.accent` | `#246B52` | Основное действие, выбранное состояние |
| `color.accent-strong` | `#19513D` | Нажатие и активное состояние |
| `color.accent-soft` | `#E7F1EB` | Фон выбранного товара |
| `color.success` | `#2D7A55` | Купленный товар и подтверждения |
| `color.danger` | `#C84B4B` | Удаление и необратимые действия |

Не использовать градиенты, большие цветные фоны, кислотные цвета и несколько конкурирующих акцентов на одном экране.

## Типографика

Основной шрифт: системный стек iOS — `-apple-system, BlinkMacSystemFont, "SF Pro Text", sans-serif`.

| Токен | Размер / начертание | Использование |
|---|---|---|
| `text.title` | 28 px / 700 | Заголовок экрана |
| `text.section` | 20 px / 700 | Заголовок категории или блока |
| `text.body` | 17 px / 500 | Название товара, основной текст |
| `text.body-small` | 15 px / 400 | Количество, заметка, вспомогательный текст |
| `text.label` | 13 px / 600 | Подписи, короткие метки |

Название товара всегда важнее количества и заметки. Не использовать текст меньше 13 px.

## Размеры и сетка

- Базовый шаг отступов: 4 px.
- Основные отступы: 8, 12, 16, 20, 24, 32 px.
- Горизонтальные поля мобильного экрана: 16 px.
- Высота основной кнопки: 52 px.
- Минимальная область касания: 44 × 44 px.
- Скругление: 12 px для полей и кнопок, 16 px для карточек, 20 px для нижних листов.
- Тень используется редко и очень мягко; по умолчанию отделять блоки границей или спокойным фоном, а не тенями.

## Изображения товаров

- Встроенные товары должны иметь небольшое изолированное изображение на светлом нейтральном фоне: фото с вырезанным объектом или единый простой иллюстративный стиль.
- Не смешивать в одной категории реалистичные фото, эмодзи и разношёрстные иконки.
- Для отсутствующего изображения использовать одинаковую нейтральную заглушку с пиктограммой категории, а не случайную картинку.
- Размер миниатюры в строке товара: 56 × 56 px; на карточке категории: 64–72 px.
- Изображение дополняет название и никогда не заменяет его.

## Компоненты

### Верхняя панель

- Белый фон, заголовок экрана слева.
- Кнопка «Назад» — иконка со словесной подписью для доступности.
- Не размещать больше одного второстепенного действия в верхней панели.

### Нижняя навигация

Три постоянные вкладки: «Новый список», «Готовый список», «В магазине».

- Высота не менее 64 px с учётом безопасной зоны iPhone.
- Активная вкладка использует `color.accent` и текстовую подпись.
- Не полагаться только на цвет: активность должна отличаться также фоном, насыщенностью или формой.

### Карточка категории

- Нажимаемая карточка на белом или мягком нейтральном фоне.
- Содержит изображение категории, название и при необходимости число выбранных товаров.
- Может быть сеткой 2 колонки на экране выбора или вертикальным списком, если названия/состояния требуют больше места.
- Не использовать более двух уровней вложенности на экране.

### Строка товара

Основной компонент выбора дома.

- Слева — миниатюра товара.
- По центру — название; ниже, если есть, количество и заметка.
- Справа — большая кнопка добавления (`+`) либо состояние «Добавлено».
- Нажатие на строку открывает редактирование количества и заметки; нажатие на `+` добавляет товар без лишнего диалога.
- Выбранный товар получает мягкий фон `color.accent-soft` и понятный индикатор выбора.

### Строка товара в магазине

- Слева — чекбокс размером не менее 24 px и миниатюра.
- По центру — название, количество и заметка.
- Нажатие на всю строку, кроме отдельных элементов управления, переключает чекбокс.
- Купленный товар: заполненный чекбокс, зачёркнутое название, ослабленный цвет текста. Он остаётся на месте, чтобы пользователь мог свериться со списком.

### Поиск

- Поле поиска на мягком фоне, с иконкой лупы и ясной кнопкой очистки.
- Плейсхолдер явно называет текущую категорию: «Найти в категории „Овощи“».
- Результаты показываются только из открытой категории.

### Кнопки

- Основная: заливка `color.accent`, белый текст. Использовать для одного главного действия на экране.
- Вторичная: светлая поверхность, граница, тёмный текст.
- Текстовая: без рамки и фона; только для второстепенных действий.
- Опасная: красный акцент — только для удаления и с подтверждением, если действие необратимо.

### Нижний лист

Использовать для добавления товара, указания количества/единицы и заметки, а также для подтверждения завершения похода. Он должен иметь заголовок, понятное закрытие и одну основную кнопку.

## Состояния и обратная связь

- Нажатие: краткое изменение фона или прозрачности, без тяжёлой анимации.
- Добавление товара: мгновенно меняется кнопка и счётчик категории.
- Пустой список: короткое человеческое объяснение и кнопка «Добавить товары».
- Нет результатов поиска: показать, что поиск ограничен текущей категорией, и предложить добавить свой товар.
- Ошибки и подтверждения писать простым русским языком, без технических формулировок.

## Правила для новых экранов

Перед созданием экрана:

1. Использовать компоненты и токены из этого файла.
2. Проверить, решает ли экран задачу из файла [Цели и проблемы пользователя.md](Цели%20и%20проблемы%20пользователя.md).
3. Оставить одно главное действие на экран.
4. Убедиться, что сценарий выполняется большим пальцем и читается на ширине iPhone.
5. Не добавлять элементы, типичные для интернет-магазина, если они не помогают вести личный список.

## Доступность

- Контраст текста и интерактивных элементов должен быть достаточным для чтения при ярком освещении магазина.
- Все иконки-действия имеют доступное текстовое название.
- Цвет не является единственным способом передать состояние.
- Не использовать жесты как единственный способ управления: у действия всегда есть видимая кнопка или строка.

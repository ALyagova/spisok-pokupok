# Спецификация: «Список покупок»

## Назначение

Создать личное мобильное веб-приложение для подготовки списка покупок дома и отметки купленных товаров в магазине. Приоритетная платформа — iPhone и Safari. Приложение открывается по ссылке; установка, аккаунт, сервер, синхронизация и уведомления не требуются.

Все пользовательские данные хранятся локально в браузере: библиотека товаров, категории, готовый список, активный список, история и частота выбора товаров.

## Разделы

Нижняя навигация содержит три раздела:

1. **Новый список**
2. **Готовый список**
3. **В магазине**

### Новый список

- Показывает категории товаров.
- При нажатии на категорию открывает товары только этой категории.
- Позволяет добавлять и убирать товары из текущего списка.
- Для товара можно задать количество, единицу измерения (шт., уп., кг, г, л и т. п.) и необязательную заметку.
- Позволяет вручную добавить товар, сразу указав категорию. Такой товар сохраняется в личной библиотеке и доступен в дальнейшем.
- Позволяет создавать собственные категории.
- Категория «Другое» предназначена для разовых и нестандартных покупок.
- Позволяет создать список с нуля, скопировать «Готовый список» или один из списков истории, а затем отредактировать копию.
- Кнопка «Начать новый поход» создаёт чистый список.

### Готовый список

- Один редактируемый шаблон частых регулярных покупок.
- Его можно изменять вручную.
- По кнопке «Использовать для нового списка» шаблон копируется в «Новый список».
- Редактирование копии не изменяет исходный готовый список.

### В магазине

- Показывает активный список, сгруппированный по категориям.
- Купленный товар отмечается галочкой и визуально зачёркивается или приглушается.
- Количество, единица и заметка из домашнего списка отображаются, но не обязательны к редактированию.
- Разрешено быстро добавлять товар вручную прямо в магазине, выбрав категорию.
- По кнопке «Завершить покупки» поход сохраняется в истории.
- В истории хранятся только два последних завершённых похода; более старый удаляется автоматически.
- Каждый список истории можно скопировать в новый список для повторного похода.
- История не должна открываться автоматически при запуске приложения.

## Категории и стартовая библиотека

Использовать типовую библиотеку продуктов для семьи из четырёх человек с детьми 3 и 9 лет:

- Молочные продукты: молоко, кефир, йогурт, творог, сметана, сыр, сливочное масло, яйца.
- Хлеб и выпечка: хлеб, батон, лаваш, булочки, печенье.
- Крупы и макароны: рис, гречка, овсянка, макароны, мука, сахар, соль.
- Мясо и птица: курица, фарш, говядина, свинина, сосиски, колбаса.
- Рыба: филе рыбы, рыба целиком, рыбные консервы.
- Овощи: картофель, морковь, лук, чеснок, огурцы, помидоры, капуста, перец, зелень.
- Фрукты: яблоки, бананы, груши, апельсины, мандарины, лимоны, ягоды.
- Заморозка: овощные смеси, ягоды, пельмени, мороженое.
- Сладости и снеки: шоколад, конфеты, вафли, чипсы, сухарики.
- Напитки: вода, сок, чай, кофе, какао.
- Хозяйственные товары: туалетная бумага, салфетки, мусорные пакеты, средство для посуды, стиральный порошок, губки.
- Другое: разовые и нестандартные покупки.

Часто выбираемые товары показываются выше в пределах своей категории. Система запоминает частоту выбора пользователя и постепенно поднимает его частые товары в начало соответствующей категории.

## Поиск

- Поиск в открытой категории выполняется только по товарам этой категории.
- Товары из других категорий в результатах не показываются.
- Поиск поддерживает интеллектуальные подсказки: начало и часть названия, распространённые варианты написания и простые опечатки.

## Дизайн

- Обязательно использовать существующую дизайн-систему владельца проекта: её токены, компоненты, цвета и типографику.
- Не создавать самостоятельную визуальную систему, если для задачи есть элементы в дизайн-системе.
- Интерфейс нейтральный, спокойный, без яркого декоративного оформления.
- Приоритет — крупные области нажатия и понятные состояния выбранных и купленных товаров на мобильном экране.
- Язык интерфейса — русский.

## Критерии готовности

1. Пользователь создаёт список из типовой библиотеки и вручную добавляет товары или категории.
2. Для позиции можно сохранить количество, единицу измерения и заметку.
3. Поиск не выходит за пределы выбранной категории.
4. Готовый список и два последних похода можно использовать как основу нового списка.
5. В магазине позиции сгруппированы по категориям и отмечаются галочкой.
6. Данные сохраняются после закрытия и повторного открытия страницы в том же браузере.
7. Визуальные решения соответствуют дизайн-системе проекта.

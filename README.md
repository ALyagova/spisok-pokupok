# Список покупок

Простое личное веб-приложение для составления списка покупок дома и отметки купленных товаров в магазине. Рассчитано в первую очередь на использование в Safari на iPhone.

## Цель проекта

Пользователь выбирает товары дома, при необходимости указывает количество, единицу измерения и заметку. В магазине открывает тот же список, сгруппированный по категориям, и отмечает товары галочкой по мере покупки.

Приложение работает без учётной записи, сервера, уведомлений и синхронизации. Все данные хранятся локально в браузере телефона.

## Разделы приложения

- **Новый список** — создание и редактирование списка перед походом в магазин. Товары выбираются внутри категорий; можно добавлять свои товары и категории.
- **Готовый список** — один редактируемый шаблон регулярных покупок. Его можно скопировать в новый список и затем изменить.
- **В магазине** — активный список покупок, сгруппированный по категориям. Купленные товары отмечаются галочкой и визуально зачёркиваются.

## Важные сценарии

1. Создать новый список, выбрав товары из типовой библиотеки по категориям.
2. Указать для товара количество, единицу измерения и необязательную заметку.
3. Добавить вручную товар внутри выбранной категории. Такой товар запоминается в личной библиотеке для будущих списков.
4. Добавить разовую покупку в категорию «Другое».
5. Создать список на основе «Готового списка» или одного из прошлых походов.
6. В магазине отмечать уже купленные позиции галочкой.
7. Завершить поход: список сохраняется в истории. В истории всегда хранится только два последних похода; более старые записи удаляются автоматически.

## Категории по умолчанию

Молочные продукты; хлеб и выпечка; крупы и макароны; мясо и птица; рыба; овощи; фрукты; заморозка; сладости и снеки; напитки; хозяйственные товары; другое.

Начальная библиотека должна содержать распространённые продукты для семьи из четырёх человек с детьми 3 и 9 лет. В каждой категории более часто выбираемые товары показываются первыми. Частота выбора пользователя дополнительно влияет на порядок внутри соответствующей категории.

## Поиск

Поиск выполняется только среди товаров открытой категории. Он не должен выдавать товары из других категорий. Поддерживаются подсказки по началу и части названия, а также распространённым вариантам написания и простым опечаткам.

## Дизайн

Для интерфейса **обязательно использовать [Дизайн-система.md](Дизайн-система.md)**. Не создавать самостоятельную визуальную систему, произвольные цвета, типографику или компоненты, если в дизайн-системе есть подходящие токены и элементы.

Продуктовый интерфейс должен оставаться нейтральным, спокойным и мобильным: крупные области нажатия, ясные состояния выбранных и купленных товаров, минимум декоративных элементов.

## Технические ориентиры

- Обычное веб-приложение, открываемое по ссылке; установка как отдельного приложения не требуется.
- Адаптивный интерфейс с приоритетом iPhone и Safari.
- Локальное хранение библиотеки, пользовательских категорий, готового и активного списков, истории и частоты выбора товаров.
- Язык интерфейса — русский.

## Критерии готовности

- Данные не теряются после закрытия и повторного открытия страницы в том же браузере.
- Поиск ограничен текущей категорией.
- Завершённые списки доступны для повторного использования, но история ограничена двумя последними походами.
- Готовый список не меняется при редактировании созданной из него копии.
- Визуальные решения и компоненты соответствуют дизайн-системе проекта.
